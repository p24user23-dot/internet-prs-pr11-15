# Mini-Backend “AI Prompt Marketplace” 🚀

Це практична робота з реалізації професійного REST API для маркетплейсу, де користувачі (Prompt Enginners) можуть ділитися та продавати свої промпти для штучного інтелекту (ChatGPT, Midjourney, Claude) з додаванням згенерованих прикладів-зображень. 

Проект виконано за допомогою стеку: Node.js, Express, Sequelize (MySQL), Zod та Jest.

## Бізнес логіка
Замість банальних "задач", API обслуговує `Prompts` (промпти для ШІ). Кожен промпт має категорію ціни (`priceCategory`), вказує для якої нейромережі він призначений (`aiModel`) і має авторів (`User`). Для демонстрації роботи промпта, автори можуть завантажити `Generations` — файли згенерованих картинок (або текстових логів).

## Технологічний стек
- **Node.js** та **Express** — сервер та маршрутизація.
- **MySQL** та **Sequelize (ORM)** — збереження даних та реляції.
- **Zod** — надійна валідація даних запитів (body, query, params).
- **Multer** — завантаження файлів-прикладів генерації (до 3 шт. на один промпт, не більше 5MB кожний).
- **Jest** та **Supertest** — модульне тестування бізнес-логіки з використанням in-memory SQLite бази даних.

## Структура бази даних
- **users** (id, name, email)
- **prompts** (id, title, description, aiModel, priceCategory, userId, createdAt)
- **generations** (id, promptId, filename, path, mimetype, size)

Зв'язки:
- Користувач `1 — N` Промпти
- Промпт `1 — N` Згенеровані файли

## Встановлення та запуск

1. **Клонування репозиторію:**
   ```bash
   git clone https://github.com/p24user23-dot/internet-prs-pr11-15.git
   cd internet-prs-pr11-15
   ```

2. **Встановлення залежностей:**
   ```bash
   npm install
   ```

3. **Налаштування бази даних:**
   Переконайтесь, що у вас працює локальний MySQL сервер (без пароля для root, якщо ви не змінювали `.env`).

   Запустіть скрипт для автоматичного створення БД (вона називатиметься `taskhub` (як історична спадщина) або можете змінити назву у `.env`):
   ```bash
   node create-db.js
   ```

4. **Запуск сервера (режим розробки):**
   ```bash
   npm run dev
   ```
   *Сервер буде працювати на порту 3000.*

## API Endpoints

### 1. Автентифікація та Користувачі
- `POST /auth/register` (або `POST /users`) — реєстрація користувача (тіло: `name`, `email`).

### 2. Промпти (Prompts)
- `POST /prompts` — створення промпту (тіло: `title`, `description`, `userId`, `priceCategory`, `aiModel`).
- `GET /prompts` — отримання масиву промптів на продаж.
  - Підтримує **пагінацію**: `page`, `limit`
  - Підтримує **фільтрацію**: `aiModel` (gpt|midjourney|claude), `priceCategory` (1-5), `search` (пошук по тексту)
  - Підтримує **сортування**: `sort` (createdAt|priceCategory), `order` (asc|desc)
- `GET /prompts/:id` — детальна сторінка промпту (разом з прикріпленими картинками).
- `PATCH /prompts/:id` — оновлення інформації про промпт.
- `DELETE /prompts/:id` — видалення.

### 3. Файли-генерації (Generations)
- `POST /prompts/:id/generations` — завантаження від 1 до 3 файлів. Дані передаються як `multipart/form-data` (ключ: `files`). 
- `GET /prompts/:id/generations` — отримання списку файлів, прикріплених до промпту.

## Тестування
Проект покритий повністю автономними Unit-тестами для перевірки створення промпту, оновлення умов та правильної роботи фільтрів/пагінації.
Запуск тестів (використовує SQLite In-Memory, не потребує піднятої MySQL):
```bash
npm run test
```
